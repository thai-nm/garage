# task-buddy

A tiny animated Claude that lives in a row above the Claude Code prompt and acts out what Claude is doing.

| Task | Buddy |
|---|---|
| Bash | runs back and forth `ᕕ( ᐛ )ᕗ` |
| Read / Grep / Glob | looks around `(⌐■_■)🔍` |
| Edit / Write | types `(•_•)⌨` |
| WebSearch / WebFetch / MCP | waves at the web `🌐 ヾ(・ω・)ノ` |
| Agent | asks a helper `(•‿•) → (•‿•)` |
| Thinking | `(・_・ ) ?` |
| Turn done | dances `♪┏(・o･)┛♪`, then naps `(-_-) zZz` |

Toggle it with `/buddy`.

## Install

From this repo's marketplace:

```
/plugin marketplace add thai-nm/garage
/plugin install task-buddy@garage
```

Or load it for one session:

```bash
claude --plugin-dir ~/workplace/personal/garage/.claude/plugins/task-buddy
```
